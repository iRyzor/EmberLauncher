# Security reporting

Please do not post credentials or exploit details that could expose user accounts in a public issue.

If GitHub's private vulnerability reporting is enabled, use **Security → Report a vulnerability** in this repository. Otherwise, contact [Ryzor](https://github.com/iRyzor) through a private contact method listed on the profile before sharing sensitive details. Do not post them publicly while waiting for a private channel.

Include the affected version, environment, impact and reproduction steps using synthetic data where possible. Do not send real STOVE tokens, QR codes, passwords, cookies, registry exports or credential-store contents.

If credentials were exposed, use STOVE's account-security controls to revoke access and remove public copies. Deleting a local file or Git commit alone does not revoke an account token.

Ember is beta software. There is no guaranteed response time or independently completed security audit. The current main branch and newest published beta are the initial focus for fixes.
